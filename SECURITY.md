# Security and Sensitive Data

MEDJEV is research software and has not been validated for clinical deployment. Never submit protected health information, identifiable clinical notes, SSH credentials, API keys, or private model artifacts in issues or pull requests.

Use GitHub's private vulnerability reporting when it is enabled for the repository. Do not open a public issue for a suspected vulnerability. If private reporting is unavailable, contact the repository maintainers through the repository's private contact channel and include a minimal reproduction, affected version, and impact assessment.
