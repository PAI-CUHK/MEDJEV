# Support

MEDJEV is alpha research software. Please use GitHub Discussions or an issue for reproducible questions about installation, the public API, or documented behavior.

When asking for help, include:

- operating system and Python version;
- MEDJEV commit or package version;
- the smallest reproducible example;
- the complete error message and relevant traceback.

Do not include patient data, private notes, credentials, model weights, or restricted datasets.
